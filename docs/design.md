# codedog 视觉规范

沿用确认的浅色三栏布局：左侧分组、中间项目列表、右侧即时详情。桌面原生标题栏、小狗图标是唯一品牌装饰，正文以项目信息为核心。

- 强调色 #6563da；选中底色 #eeeefe；画布 #ffffff；侧栏 #f5f6fa；文字 #242737；细边框 #e8e9ef。
- 品牌采用紧凑粗体小写 codedog；正文使用系统无衬线；路径和依赖使用系统等宽。
- 侧栏 224px；右侧详情 318px；列表占用其余空间；低宽度下收紧侧栏并隐藏次要时间列。
- 控件 5–7px 圆角；小型项目标记 8px；仅浮层使用明显阴影。
- 状态色只传达就绪、待安装与路径缺失。键盘焦点可见，支持减少动态效果。

参考：https://www.shadcn.io/design/linear/raw 。浅色方案属于演绎，非对该深色营销规范的逐项复刻。
