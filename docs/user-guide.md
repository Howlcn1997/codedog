# codedog 用户指南

## 第一次打开

codedog 会自动寻找常见的代码目录（如 `~/codespace`、`~/Projects`、`~/Developer`），找到后立刻开始扫描。如果你用过旧版 codedog，收藏、标签、备注等会被自动导入。

想换扫描目录：**设置 › 扫描**，添加或移除文件夹。codedog 最多向下找 5 层，遇到 `.git`、`package.json`、`go.mod`、`pyproject.toml`、`Cargo.toml`、`*.xcodeproj` 等标志就认定为一个项目，不再往里钻；`node_modules`、`dist`、隐藏目录等会被跳过。

不在扫描目录里的项目：工具栏 **＋ › 添加已有文件夹…**。

## 主窗口

**侧栏**

| 分组 | 说明 |
|---|---|
| 快速筛选 | 收藏、等你回复、最近打开、未提交、占空间（≥500 MB）、已隐藏 |
| 标签 | 你自己的分组，一个项目可以有多个标签；右键标签可以"一起打开"（生成多根工作区，用 VS Code 系编辑器打开） |
| AI 助手与编辑器 | 用过 Claude Code、Codex、VS Code、Cursor 等的项目 |
| 项目形态 | 网页、App、后端服务、工具脚本、库、其他（根据项目文件推断） |

**今日脉搏**：页头的四个指标块——运行中、等你回复、未提交、本周活跃。点一下只看这类项目，再点取消。

**项目卡**：左上角是技术栈徽章；卡片底部是近 28 天的活跃度（提交 + AI 回复）、用过的 AI 工具、最近活动时间、占用空间和分支；右下角的标记表示"运行中 / 等你回复 / N 未提交"。

**时间与排序**：工具栏的筛选按钮里可以只看最近 7 天 / 30 天 / 3 个月 / 半年活跃的项目，或按最常打开、名称、创建时间、占用空间排序。`⌘⇧L` 在卡片与列表之间切换。

## 项目面板

点任意卡片，右侧滑出项目面板（`Esc` 关闭）：

- **操作栏**：有 AI 会话时主按钮是"续上 Claude Code / Codex"，否则是"用编辑器打开"；旁边是终端、访达、远程仓库、收藏和更多菜单（新会话、换编辑器打开）。
- **指标块**：30 天提交、30 天 AI 回复、估算花费、未提交文件数。
- **近一年圆点图**：每列一周、每行一天，可切换"全部 / 提交 / AI"。提交只统计你自己的（按仓库的 `user.email`）。
- **AI 会话**：最近 6 个会话，每个都可以单独续上。
- **模型用量**：按模型的 token 与估算花费。花费按 Anthropic 公开 API 价格估算，只覆盖 Claude 模型，订阅用户的实际花费不同。
- **Git**：分支、未提交文件数与最近提交时间线。
- **磁盘**：源码与依赖/缓存各占多少，一键清理依赖。
- **笔记**：标签、备注、项目专属编辑器、README。

## 启动器

在任何 App 里按 `⌘⇧Space`（可在 设置 › 通用 修改）：

| 按键 | 作用 |
|---|---|
| 输入 | 搜索；不输入时列出最常用的项目 |
| `↑` `↓` | 选择项目 |
| `←` `→` | 切换底部的操作（编辑器 / 续上 AI / 终端 / 访达 / 仓库） |
| `↵` | 执行选中的操作 |
| `⌘↵` | 续上上次的 AI 会话 |
| `⌥↵` | 在终端打开 |
| `Esc` | 清空输入；再按一次关闭 |

## 续上 AI 会话

codedog 读取 `~/.claude/projects` 与 `~/.codex/sessions` 里的会话记录（只读），把会话归到所在的项目上。点"续上"时，codedog 会打开终端执行 `claude --resume <会话>` 或 `codex resume <会话>`。

- 第一次使用时 macOS 会询问是否允许 codedog 控制"终端"，请允许。
- 默认终端在 设置 › 打开方式 中选择；目前 Terminal 与 iTerm2 支持自动执行命令，其他终端会用系统终端代替。
- "等你回复"：AI 的最后一条消息已经结束、你在 48 小时内还没有回复。

## 清理磁盘

codedog 在后台统计每个项目的大小，区分源码与可再生目录：`node_modules`、`.venv`、`venv`、`Pods`、`.next`、`.nuxt`、`.turbo`、`.parcel-cache`，以及 Rust 项目的 `target`。

- 单个项目：项目面板 › 磁盘 › 清理依赖与缓存。
- 批量：侧栏 **占空间** › 清理…，勾选要清理的项目。

清理会把目录**移到废纸篓**，需要时可以还原；重新安装依赖或构建即可恢复。移走前会逐个确认目录真实存在、不是符号链接、位于项目内部。

## 菜单栏与后台

设置 › 通用 › **常驻菜单栏** 打开后，关闭主窗口时 codedog 留在菜单栏（Dock 图标随之隐藏），随时可以用快捷键呼出启动器。菜单栏菜单里有等你回复的项目和最近打开的项目。

**登录时启动** 也在 设置 › 通用。

## 命令行

设置 › 通用 › 命令行工具 › 安装到 `~/.local/bin`。如果 PATH 里没有这个目录，在 shell 配置里加入 `export PATH="$HOME/.local/bin:$PATH"`。

```sh
codedog web              # 用编辑器打开名称或搜索词匹配的项目（等同于 codedog open web）
codedog open -t web      # 在终端打开；-f 在访达中显示
cd "$(codedog path web)" # 跳到项目目录
codedog list lottie      # 搜索并列出项目（--all 包含已隐藏）
codedog add .            # 把当前目录加入 codedog
```

匹配规则：名称完全一致优先，其次是搜索结果恰好只有一个；有多个候选时会列出来。

## 更新

codedog 每天检查一次 GitHub Releases，有新版本时在侧栏底部和菜单栏提示，点击即打开下载页（也可以在 设置 › 通用 › 更新 中手动检查或关闭）。因为没有开发者签名，新版本需要手动下载替换，替换后执行一次 `xattr -dr com.apple.quarantine /Applications/codedog.app`。

## 数据在哪里

`~/Library/Application Support/codedog/`：

| 文件 | 内容 |
|---|---|
| `library.json` | 你的数据：扫描目录、标签、收藏、备注、项目编辑器、偏好。唯一需要备份的文件 |
| `cache.json` | 扫描结果缓存，可删除，下次启动重建 |
| `ai-cache.json` | AI 会话摘要缓存，可删除 |
| `sizes.json` | 占用空间缓存，可删除 |
| `projects.json` | 旧版数据，只在首次启动时读取一次 |
