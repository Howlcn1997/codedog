# 图标来源

`App/Resources/Assets.xcassets/Stack/` 中的语言与框架图标来自 [Simple Icons](https://simpleicons.org) 16.30.0，按 [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) 协议使用；徽章底色取自 Simple Icons 收录的官方品牌色。

这些图标是对应项目或公司的商标，codedog 只用它们标识项目所用的技术，不代表任何官方关联或背书。

AI 助手与编辑器图标不随应用分发，运行时读取本机已安装 App 的图标，未安装时使用 SF Symbols。
