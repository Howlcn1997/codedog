# IDE menu icons

These transparent glyphs are bundled for native context menus. The Cursor and
JetBrains glyphs are sourced from Simple Icons (CC0 1.0); the Visual Studio Code
glyph is based on Microsoft's official VS Code logo. Product names and marks are
the property of their respective owners.

The 16px PNG is the standard-resolution menu image and the `@2x` PNG is its
Retina representation. On macOS they are rendered as template images so they
remain legible in both light and dark menus.
